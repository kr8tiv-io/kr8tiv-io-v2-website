# Vengeons framework vs kr8tiv.io (Nov 6 2026)
Source: Paul Vengeons, "The Google Algorithm Explained, In Depth…" https://x.com/VengeonsP/status/2118661285868863578
No Search Console export on disk — every query/CTR claim below needs Matt's GSC paste.

## 1. Scouts (crawl/render/index)
Good: Astro static = answers in raw HTML; service pages carry title/H1 with query words ("Storefront & Sign Design in Edmonton"); HowTo schema; robots.txt, llms.txt, sitemap exist; type is live HTML over video plates (not baked in).
Gaps: verify video/JS hero doesn't push the H1+answer below hydration; first 100 words must contain the query + Edmonton; sitemap must exclude noindex drafts, /menu-lab, /build-notes; internal links into new service pages are thin (mostly nav).

## 2. Judge (siteAuthority, focus/siteRadius, contentEffort)
Good: tight focus = "Edmonton creative studio: web, brand, print/signage". Real pricing (web from $1,200, landing $600, sign concept ~$500 + variable PM) is first-hand material.
Gaps: little proof a human did it — no process photos, real project notes, fabricator workflow detail, author bylines on Field notes. Home (strongest page) should link down to each service with descriptive anchors.

## 3. NavBoost (click, stay, return)
Gaps: titles are descriptive but not click-winning; first screen should answer "what, price, Edmonton, next step" before scroll; nothing yet drives brand returns (Field notes series, newsletter, "KR8TIV" branded searches).

## 4. Bouncer (demotion)
Risks for us: (a) spinning one page per collateral item × city = thin scaled pages; (b) FAR queries (generic "logo ideas", "what is SEO") dilute siteRadius; (c) keyword-stuffed anchors; (d) publishing 5 drafts without first-hand effort.
Rule: one strong collateral hub + a few deep children only where there is real distinct demand and real material.
